プライバシーポリシー

yt-auto は、開発者本人が自分のパソコン上で、自分の YouTube チャンネルに動画を投稿するためだけに使う個人用ツールです。

  • YouTube Data API を使い、本人のチャンネルへの動画のアップロード、サムネイルの設定、投稿先チャンネル名の確認だけを行います。
  • Google から受け取った認証情報は本人のパソコン内にだけ保存し、外部のサーバーに送ったり、第三者に提供したりすることはありません。
  • 本人以外のユーザーの情報を集めることはありません。
  • 許可は Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

yt-auto's use of information received from Google APIs adheres to the YouTube API Services Terms of Service and Google API Services User Data Policy. No user data is collected, stored on any server, or shared with third parties. Credentials are stored only on the owner's own computer.
